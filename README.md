# Glowing Life

The website for **Glowing Life**, a cozy game about a small light being in a
world that has gone out. Wherever you go, life comes back.

Live at <https://mysticartstudio.github.io/glowing-life/>

Play the demo, free and in your browser:
<https://mysticartstudio.itch.io/glowing-life>

This repository holds the website only: one `index.html` and four images, no
build step. The game itself is not part of it.
